# 🎵 ScreenSound 2.0

O **ScreenSound** é uma aplicação de console desenvolvida em C# para o gerenciamento de bandas, álbuns e avaliações. O projeto faz parte da formação de C# da Alura e demonstra conceitos fundamentais de Programação Orientada a Objetos (POO) e integração com APIs externas.

## 🚀 Funcionalidades

- **Gerenciamento de Bandas:** Registro de novas bandas com resumos automáticos gerados por Inteligência Artificial.
- **Integração com IA:** Utiliza a API da OpenAI (GPT-4o-mini) para criar descrições criativas sobre as bandas registradas.
- **Sistema de Avaliação:** Permite atribuir notas para bandas e álbuns.
- **Exibição de Detalhes:** Visualização completa das informações de uma banda, incluindo sua média de notas e resumo.

## 🛠️ Tecnologias Utilizadas

- **C#** e **.NET**
- **OpenAI API** (para geração de conteúdo)
- **Microsoft.Extensions.Configuration** (para gerenciamento seguro de chaves de API)
- **Git & GitHub** (para versionamento)
